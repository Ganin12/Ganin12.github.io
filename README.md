# Траты — учёт расходов (PWA)

Все данные хранятся только в браузере устройства (localStorage).

## Как запустить
1. Выложите содержимое папки на любой HTTPS-хостинг, например GitHub Pages.
2. Откройте ссылку на телефоне и выберите «Установить» / «Добавить на главный экран».
3. Камера работает только по HTTPS.

## Чеки по QR
В QR российского чека есть только дата и сумма. Товары подтягиваются через proverkacheka.com:
получите токен в профиле сайта и вставьте его в приложении (Категории, Чеки по QR).
Запрос идёт напрямую с телефона, доступ из браузера (CORS) и формат ответа нужно проверить на реальном чеке.
Без токена или при ошибке сохраняются дата и сумма.
